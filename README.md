# 途中过分相+升降弓

HXD1C 浏览器虚拟考核项目。项目由已验收的途中瞭望项目完整复制后独立建立，来源项目不会被本仓库的修改覆盖。

## 入口

- 项目首页：`/`
- 主考核：`/power-training/`
- 仅设考核模式；单人操作，系统模拟副司机应答。

## 场景

项目以 55 km/h 稳定运行、后弓单弓、主断合、空压机自动为初始状态。

1. 手动过分相（60分）
   - 分相预告标、禁止双弓标、T断标、断标、实体分相起止、合标。
   - T断后、断标前完成分主断。
   - 越过合标 5–20 m 内允许合主断。
   - 正反方向牌面均保留。
2. 临时升降弓与接触网异物处置（40分）
   - 另一固定地点设置临时升降弓标和现场手信号。
   - 每局在固定位置随机生成红色塑料袋、红色塑料布、风筝或树枝侵入接触网。
   - 采用后弓完成降弓、通过异物区和升弓恢复。

安全关键错误使对应场景记 0 分，但考核继续，成绩单保留里程、速度、设备状态和操作时间线。

## 开关口径

- 受电弓：`升 / 0 / 降`，操作后保持目标位。
- 主断路器：`合 / 0 / 分`，操作后保持目标位。
- 空压机：`强泵 / 自动 / 停止`，初始并建议保持自动；不计核心分。

开关界面内可打开原游戏驾驶台截图和实车板钮照片进行对照。原游戏只显示受电弓状态，没有这三项可操作三位置开关；新项目按本地实车板钮参考照片和既有模拟器状态定义实现。

## 本地运行与校验

```powershell
python -m http.server 4175

```
