# 途中过分相+升降弓

HXD1C 浏览器虚拟考核项目。项目由已验收的途中瞭望项目完整复制后独立建立，来源项目不会被本仓库的修改覆盖。

## 入口

- 项目首页：`/`
- 主考核：`/power-training/`
- 仅设考核模式；单人操作，系统模拟副司机应答。

## 场景

项目以 55 km/h 稳定运行、后弓单弓、主断合、空压机自动为初始状态。

1. 手动过分相（60分）
   - 分相前位置确认、禁止双弓标、T断标、断标、实体分相起止、合标。
   - T断后、断标前完成分主断。
   - 越过合标 5–35 m 内允许合主断；这是对 55 km/h 网页板钮操作延迟的考核容差。
   - 正反方向牌面均保留。
2. 临时升降弓与接触网异物处置（40分）
   - 另一固定地点设置临时升降弓标，不再设置人员或现场手信号。
   - 每局在固定位置随机生成红色塑料袋、红色塑料布、风筝或树枝侵入接触网。
   - 采用后弓完成降弓、通过异物区和升弓恢复。

线路中的禁止双弓、断、合、准备降弓、降弓和升弓标均由原游戏 JINGGUANG 路线 `.s` 模型直接导出，保留原纹理、牌面比例和反方向牌面。三道斜杠式进站预告标不属于电分相标志，已从本考核移除；原场景自带的重复断电牌、禁止双弓牌、曲线牌及无关信号机也在本项目内过滤。原路线没有独立的 `T断` 模型，因此该牌按同组菱形标牌制式补绘，并在场景对象中明确标注为补充资产。钢轨复用“途中瞭望技巧”已验收的原游戏轨道纹理、实体尺寸和视口自适应双层远景显示。

为保证带驾驶台视场下可辨认，教学场景对标牌做了等比例显示补偿，并按“禁止双弓→T断→断→分相区→合”布置；这不会改动原模型源文件。

安全关键错误使对应场景记 0 分，但考核继续，成绩单保留里程、速度、设备状态和操作时间线。

## 开关口径

- 受电弓：`升 / 0 / 降`，操作后保持目标位。
- 主断路器：`合 / 0 / 分`，操作后保持目标位。
- 空压机：`强泵 / 自动 / 停止`，初始并建议保持自动；不计核心分。

主考核直接复用原项目完整 HXD1C 驾驶台：牵引／电制动主手柄、换向手柄、自动制动阀、单独制动阀、停放制动、两组风压表、速度表、网压／电流、LKJ 和 CIR 均保留原交互逻辑。

板钮面板沿用原项目的实物照片式外观，点击驾驶台中部板钮区域打开。面板停靠在驾驶台下部，不使用全屏遮罩，不遮挡上方线路运行画面。三个关键板钮按本项目要求扩展为保持式三位置开关。
